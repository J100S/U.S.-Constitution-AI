# 🇺🇸 Constitutional AI (Browser Chatbot)

A modern, browser-based AI chatbot that combines:
- 📜 U.S. Constitution knowledge engine  
- 🌍 Wikipedia-powered information lookup  
- 🧠 GPT-style conversation memory simulation  
- 🇺🇸 USA-themed UI with animated modern design  

Built using **HTML, CSS, and JavaScript**, fully compatible with **GitHub Pages** (no backend required).

---

## ✨ Features

### 🧠 AI System
- Context-aware conversation memory (remembers what you’re talking about)
- Multi-turn understanding (e.g., “who is the president” → “what is his name” works)
- GPT-style context window simulation (stores last messages)
- Intelligent routing between Constitution and Wikipedia

### 📜 Constitution Engine
- Detects legal/government-related questions
- Explains amendments in simple language (not just raw text)
- Focuses on meaning and interpretation

### 🌍 Wikipedia Integration
- Uses Wikipedia API for real-world knowledge
- Filters irrelevant results (e.g. disambiguation pages, actor lists)
- Summarizes responses into short AI-style answers

---

## 🎨 UI Features

- 🇺🇸 USA-themed modern design
- Glassmorphism chat window
- Smooth animations for messages
- Responsive layout (works on mobile + desktop)
- Dark animated background
- Clean chatbot-style interface
